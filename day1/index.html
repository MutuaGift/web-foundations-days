Welcome to QuickNotes

QuickNotes is a lightweight note-taking app built for capturing thoughts the moment they occur. This is the Day 1 page of the project: a simple, semantic HTML5 skeleton that later days will build on.

What's on this page

  • A semantic HTML5 document skeleton with header, main and footer
  • Site navigation that links to the home page and the about page
