About QuickNotes

QuickNotes is a lightweight note-taking app for capturing thoughts the moment they occur. It keeps every note short, searchable and easy to retrieve, so you can stay focused on the work in front of you.

How to use QuickNotes

  1. Open QuickNotes and choose New note to start from a blank page.
  2. Type your note, giving it a short title so it is easy to recognise later.
  3. Press Ctrl + S to save the note to your library.
  4. Use the search box to find a saved note by title or by keyword.

Features

  • Fast capture: open a note and start typing with no setup
  • Full-text search across every saved note
  • Tags and notebooks for organising notes by project or topic
  • Offline storage, so your notes stay on your own device
  • Keyboard shortcuts for the most common actions

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
Ctrl + F Search all saved notes
Ctrl + / Show the list of keyboard shortcuts
